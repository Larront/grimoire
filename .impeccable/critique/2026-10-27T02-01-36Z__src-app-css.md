## Design specificity

Several libraries' defaults stitched together, not a house style. Dialects: tw-animate fade+zoom for floating surfaces (100ms, ease); sheets (200ms ease-in-out, scrim instant); Svelte `slide` for the sidebar groups and tree folders (400ms, height/padding/margin); grid-rows for the scene mixer and timeline (200/150ms); instant collapse for callout and statblock (chevron only); shadcn width for the rail and docked panel (200ms linear); sonner toasts (400ms ease). No motion tokens exist. Nothing bounces or overshoots.

Detector: CLI 3 advisory findings, none motion-related (all false positives); live overlay found no motion anti-pattern in any view. B's measurements confirm every A finding: slides keep 400ms under reduce motion; the Splash's second column waits 150ms then pops; the tree chevron selector matches 0 elements; toasts are unmounted at ~200ms of a 400ms exit; callout and statblock snap.

## Priority issues

**[P0] The app's Reduce Motion setting misses JS-driven motion.** Svelte transitions run on the Web Animations API, out of reach of the CSS `!important` rule: tree folders and the Files/Scenes groups slide 400ms with the setting on (FileTree.svelte:680, AppSidebar.svelte:523, SidebarScenes.svelte:68). The floating detail panel's 200px fly and the block handle read only the OS query; `scrollIntoView` smooth and the graph search fit are ungated. The rule zeroes durations but not delays (Splash column hidden 150ms). Fix: one motion source from appPrefs, all JS motion reads it, CSS also zeroes delays.

**[P1] Expand/collapse has no shared technique** — snap (callout, statblock, pin Appearance), grid-rows (mixer, timeline), 400ms slide (tree, sidebar groups); four chevron behaviours; the tree chevron never turns (selector one div short, FileTree.svelte:622).

**[P1] Layout properties animate** — tree row hover animates padding 8→32px (sidebar-menu-button.svelte:8); docked panel and rail animate width linearly, re-wrapping the note; buttons `transition-all`; volume slider width/left.

**[P2] Search pulse doesn't pulse** (`::selection` can't animate; 600ms hard crimson then snap). **[P2] Toast exits cut off** at ~30% opacity; 400ms entry is the slowest motion in the app. **[P2] Now-playing bars freeze differently** under the app setting and the OS route.

**[P3]** Sheet scrim snaps while the sheet slides; slash/link menus and link preview appear instantly while other menus fade.
